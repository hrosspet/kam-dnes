# kam-dnes

A small offline-capable web app (PWA) that shows where to go after school today and on the next few days.

Data comes from the published-to-web CSV of the planning sheet (`CSV_URL` in `app.js`). The app stores the last downloaded plan on the phone and warns when it is stale or has no entry for today.

Install on Android: open the page in Chrome → menu → "Add to Home screen" / "Install app".
